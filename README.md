# 🏏 BPL Dream11 Team Builder

## 🚀 Live Demo

🔗 https://bpl-dream11-team-builder.vercel.app

---

## 📌 Overview

BPL Dream11 Team Builder is a dynamic web application where users can build their own fantasy cricket team based on players.

Users can select players, manage budget/limits, and create a complete team just like a real Dream11 experience — all within a clean and responsive interface.

This project is built using **React + Tailwind CSS**, focusing on component-based architecture and interactive UI.

---

## ✨ Features

* 🧑‍🤝‍🧑 **Player Selection System**
  Add players to your dream team

* ❌ **Remove Player Option**
  Easily remove players from the selected list

* ⚠️ **Selection Limit Control**
  Prevents exceeding team/player limits

* 🔔 **Toast Notifications**
  Instant feedback using React Toastify

* 📱 **Fully Responsive Design**
  Works smoothly on mobile, tablet, and desktop

* ⚡ **Dynamic UI Updates**
  Real-time state management with React
